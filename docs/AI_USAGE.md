# AI 輔助開發紀錄

本專案使用 OpenAI Codex 協助讀取作業 PDF，整理軟體規格，實作 C++ / Qt 介面、Voronoi divide-and-conquer 核心、輸出入解析、幾何與介面測試、建置與部署腳本，以及使用文件。

核心由排序、遞迴子圖、共同切線、中垂線合併鏈與裁邊構成；沒有使用第三方 Voronoi / Delaunay 套件。測試使用另一個全點集半平面計算方式作為 oracle，以避免只用核心的相同實作互相比對。

實際操作與驗證包含：獨立幾何比對、重複／共線／共圓案例、PDF 的逐行輸出範例、Qt 滑鼠和按鈕操作、文字檔 roundtrip 與介面截圖檢查。具體測試輸出可重新執行 README 的指令取得。

使用者仍應自行理解、驗證並能解釋演算法；於正式報告補上自己的實驗環境、學號姓名、測試數據、心得，以及需要的對話摘錄。本文件不代填個人資訊，也不虛構人工測試或課程查驗成果。
